🫁 Pulmo AI — Lung Disease Detection using Deep Learning
📌 Overview

Pulmo AI is an AI-powered medical image classification system designed to detect lung diseases from chest X-ray images. The model is trained using Convolutional Neural Networks and enhanced with Grad-CAM explainability to visualize disease-relevant lung regions.

🎯 Features

Multi-class lung disease classification

CNN-based deep learning model

Grad-CAM explainability visualization

Flask web deployment

Modern UI with background styling

🧠 Diseases Detected

COVID-19

Pneumonia

Tuberculosis

Normal

🧰 Tech Stack

Python

TensorFlow / Keras

OpenCV

Flask

NumPy

Matplotlib

HTML / CSS

📊 Model Details

Input Size: 224×224

Architecture: CNN with Global Average Pooling

Optimizer: Adam

Loss: Categorical Crossentropy

🔬 Explainability

Grad-CAM is used to generate class activation heatmaps to improve model interpretability.

🌐 Web Application

Users can upload chest X-ray images and receive disease predictions through a Flask-based interface.
